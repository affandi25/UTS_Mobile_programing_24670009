POIN 1 NAMA DAN TUJUAN APLIKASI

1.1. Identitas & Nama Aplikasi

Aplikasi mobile yang dibangun bernama "Sweet Dessert & Donut App" (SweetBite Mobile). Aplikasi ini merupakan sistem digital pemesanan makanan/dessert modern (F&B) spesialis donat gulung dengan berbagai pilihan topping dan rasa premium, dirancang berbasis Flutter dengan antarmuka presisi tinggi sesuai standar UI/UX modern.

1.2. Tujuan Pengembangan Aplikasi

  • Solusi Pemesanan Praktis (F&B): Memberikan kemudahan bagi konsumen (khususnya mahasiswa dan masyarakat) untuk menjelajahi katalog donat, mengecek promo kupon diskon, kustomisasi topping, serta memilih metode pembayaran secara instan tanpa perlu antre di gerai fisik.
  • Antarmuka Menarik & Responsif (Rich Aesthetics): Menyajikan visual hangat bergaya warm gold dan navy yang estetik, navigasi intuitif, serta tata letak responsif di smartphone.
  • Pemenuhan Capaian Pembelajaran Mobile Programming: Mengimplementasikan seluruh materi kuliah Flutter: UI Dasar, Layouting (Row & Column), Spacing terukur, Media Gambar lokal dengan BoxFit, dan Navigasi LIFO Stack (Navigator.push & pop).

POIN 3 PENJELASAN WIDGET DAN MATERI FLUTTER YANG DITERAPKAN

Berikut adalah penjelasan konkret implementasi seluruh materi wajib UTS Mobile Programming pada kode sumber proyek:

3.1. UI Dasar Flutter (Text, TextStyle, Icon, Color, Container)

  • Text & TextStyle: Mengatur tipografi seluruh antarmuka (fontSize, fontWeight: FontWeight.bold/w900, letterSpacing, color, textAlign). 
    // Text & TextStyle pada Header Onboarding & Beranda
const Text(
  'ENJOY YOUR FOOD',
  textAlign: TextAlign.center,
  style: TextStyle(fontSize: 26, fontWeight: FontWeight.w900, letterSpacing: 2.0, color: AppColors.textDark),
)
  • Icon: Pustaka Material Icons komunikatif: Icons.home_filled, Icons.grid_view_rounded, Icons.receipt_long_rounded, Icons.person_outline_rounded, Icons.search, Icons.star_rounded, Icons.lock_outline.
  • Color: Terpusat di core/app_colors.dart: Gold Primer (#D4A017), Navy Button (#2A5EB0), Background (#FDFBF7), Gray Input (#F1F3F6), Dark Text (#1E2022).
  • Container: Pembungkus serbaguna dengan BoxDecoration, borderRadius, boxShadow, border, dan LinearGradient untuk menghasilkan efek visual modern.

3.2. Layouting (Row, Column, dan Kombinasi Keduanya)

  • Column: Menyusun elemen vertikal: susunan form input login, alur sambutan onboarding, dan seksi konten beranda.
  • Row: Menyusun elemen horizontal: header nama & avatar profil, rating bintang & harga donat, serta counter jumlah [-] [+].
  • Kombinasi Row & Column: Diterapkan pada kartu donat Best Seller dan kartu Katalog Menu: induk kartu memakai Row (memisahkan foto produk dan rincian info), lalu di dalamnya disusun memakai Column (Nama → Rating → Harga → Tombol PESAN). 
    // Kombinasi Row dan Column pada Kartu Menu Katalog
Card(
  child: Row(
    children: [
      ClipRRect(child: Image.asset(item.image, width: 85, height: 85, fit: BoxFit.cover)),
      const SizedBox(width: 14),
      Expanded(
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text(item.name, style: const TextStyle(fontWeight: FontWeight.bold)),
            Row(children: [const Icon(Icons.star, color: Colors.amber, size: 14), const Text(' 4.8')]),
            Text('Rp ${item.price}', style: const TextStyle(color: AppColors.primaryGold, fontWeight: FontWeight.bold)),
          ],
        ),
      ),
    ],
  ),
)

3.3. Spacing (Margin, Padding, dan SizedBox)

  • Margin: Memberikan jarak luar antar elemen kartu, contoh: margin: const EdgeInsets.symmetric(horizontal: 16, vertical: 8) pada item katalog agar tidak berhimpitan.
  • Padding: Memberikan ruang lapang di dalam kontainer, contoh: padding: const EdgeInsets.symmetric(horizontal: 32.0) pada onboarding dan form input.
  • SizedBox: Pemisah jarak tetap yang efisien, contoh: SizedBox(height: 18) untuk jarak vertikal antar form input, dan SizedBox(width: 12) untuk jarak horizontal antar tombol.

3.4. Pengelolaan Gambar (Image.asset, Ukuran, dan BoxFit)

  • Image.asset(): Memanggil aset gambar lokal dari folder asset/ yang terdaftar pada pubspec.yaml.
  • Pengaturan Ukuran & BoxFit: Menggunakan width & height eksplisit dengan BoxFit.cover (pada kartu donat dan avatar profil agar proporsional memenuhi kontainer) dan BoxFit.contain (pada logo onboarding agar gambar tidak terpotong).
  • ClipRRect & ClipOval: Menghasilkan sudut gambar melengkung halus (BorderRadius.circular(16)) dan avatar bundar sempurna. 
    // Penggunaan Image.asset() dengan BoxFit dan Dimensi
ClipRRect(
  borderRadius: BorderRadius.circular(16),
  child: Image.asset('asset/bestseller_tiramizu.png', width: 110, height: 110, fit: BoxFit.cover),
)

3.5. Manajemen Navigasi Multi-Halaman (Navigator.push & Navigator.pop)

Mengintegrasikan 7 halaman lengkap menggunakan konsep tumpukan riwayat (LIFO Stack Navigation):

  • Navigator.push(): Menumpuk halaman baru ke atas riwayat (Beranda → Menu → Detail Pesanan → Profil).
  • Navigator.pop(): Mencabut halaman teratas saat tombol panah kembali diklik, mengembalikan user ke halaman sebelumnya.
  • Navigator.popUntil(): Langsung kembali ke Beranda utama (route.isFirst) saat ikon Beranda ditekan.
  • Navigator.pushReplacement() / pushAndRemoveUntil(): Digunakan saat Onboarding, Login, dan Logout.

POIN 5 PENJELASAN ALUR NAVIGASI DAN PENGIRIMAN DATA ANTARHALAMAN

5.1. Alur Transisi & Logika Tumpukan LIFO (Last-In, First-Out)

Peta Alur Transisi Halaman:
[Onboarding] → pushReplacement → [Login / Register] → pushReplacement → [Beranda (HomeScreen - Root Stack)]
• Dari Beranda → push → [Katalog Menu] / [Pesanan Saya] / [Profil Pengguna]
• Dari Katalog Menu → push → [Detail & Pesanan Saya]
• Tombol panah atas (←) → Navigator.pop(context) → Kembali ke halaman sebelumnya secara berurutan.
• Tab bawah Beranda → Navigator.popUntil(context, (r) => r.isFirst) → Langsung ke Beranda tanpa duplikasi.
Aksi Navigasi Metode Flutter Efek Terhadap Tumpukan Route (Stack)
Mulai Aplikasi (Get Started) Navigator.pushReplacement() Mengganti Onboarding dengan LoginScreen; mencegah user kembali ke splash screen.
Submit Login Berhasil Navigator.pushReplacement() Menjadikan HomeScreen sebagai rute dasar (route.isFirst).
Buka Menu / Detail / Profil Navigator.push() Menumpuk halaman baru ke atas riwayat (mempertahankan urutan LIFO stack).
Klik Tombol Panah Kembali (←) Navigator.pop(context) Mencabut layar paling atas dan kembali ke layar persis di bawahnya.
Klik Tab Beranda di Nav Bawah Navigator.popUntil((r) => r.isFirst) Mencabut seluruh layar di atas tumpukan hingga tersisa Beranda dasar.
Keluar Akun (Logout) Navigator.pushAndRemoveUntil() Menghapus seluruh tumpukan rute dan membuka LoginScreen sebagai layar bersih.

5.2. Pengiriman Data Antarhalaman (Data Passing via Constructor)

Pengiriman data antarhalaman dilakukan secara terstruktur melalui parameter konstruktor widget:

  • Pengiriman Search Query Beranda → Menu:
    Saat user mencari kata kunci pada Search Bar Beranda, query teks dikirimkan ke MenuCatalogScreen(initialQuery: queryTeks). Pada method initState(), nilai tersebut langsung menyaring daftar varian donat secara otomatis. 
    // Pengiriman Search Query dari HomeScreen ke MenuCatalogScreen
Navigator.push(context, MaterialPageRoute(builder: (_) => MenuCatalogScreen(initialQuery: searchController.text)));
  • Pengiriman Item Terpilih Beranda/Menu → Detail Pesanan (MyOrderScreen):
    Menekan tombol "PESAN" mengirimkan data nama produk, harga, dan thumbnail gambar ke konstruktor MyOrderScreen untuk ditampilkan pada ringkasan pesanan dan dihitung subtotalsnya.
  • Sinkronisasi State Menu Bawah (AppBottomNavBar):
    Menerima parameter currentIndex (0: Beranda, 1: Menu, 2: Pesanan, 3: Profil) untuk mengaktifkan warna emas primer pada ikon yang sedang aktif.
